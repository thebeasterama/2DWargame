# Iron Front

A self-contained tactical 2D browser wargame.

## Run

Open `index.html` in a browser, or serve the folder:

```bash
python3 -m http.server 8080
```

Then visit `http://localhost:8080`.

## Controls

- **WASD**: Move the active unit
- **1–3**: Select a unit
- **Click**: Target an enemy
- **Space**: Attack
